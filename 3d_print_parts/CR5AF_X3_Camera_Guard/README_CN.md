# CR5AF X3 末端相机保护支架

面向 Dobot CR5AF 机械臂、reBot B601-DM / DM4310 夹爪执行器组件与 Insta360 X3 相机的末端相机安装及保护结构项目。

> **状态：工程样机 / 分析版本。尚未取得安全认证，也未完成真实碰撞试验。**
>
> 本目录首批提交为文档与来源说明。当前完整 CAD 资料包含有第三方参考几何；在核清来源和再分发许可前，不公开上传这些第三方模型或混合装配文件。

## 设计目标

- 在 CR5AF 末端附近以名义 45° 角度安装 Insta360 X3。
- 相比早期长支架缩短相机支架的力臂。
- 探索相机保护框一体化及免工具 / 快拆安装。
- 探索可更换的牺牲式连接结构，用于碰撞管理。
- 设置独立防坠路径，避免相机模块释放后直接坠落。

## 硬件范围

- 机械臂：Dobot CR5AF（加工前核对具体型号和法兰版本）。
- 夹爪：reBot B601-DM；所参考套件使用 DM4310 执行器。
- 相机：Insta360 X3。
- 打印件：底座 / 直连安装件、可更换保险卡匣及保持结构、短 45° 一体相机模块。

本仓库不再分发厂家机械臂 CAD、相机网格、电机网格或其他第三方资产。请从相应制造商处获取，并遵守其使用条款。

## 分析状态

针对 V2R1 几何版本形成了有限元和结构评审资料，覆盖静力工况、模态结果、稳态谐响应数据、网格敏感性记录、连接 / 间隙审查以及防坠绳能量敏感性模型。

重要限制：

- 数值结果依赖理想化约束、材料假设、载荷方向及简化的接触 / 紧固件模型。
- 当前模型**不能证明保险颈必然先于其他结构失效**。
- 防坠绳必须连接到独立于快拆卡扣的承载路径；否则卡扣释放时可能同时失去防坠功能。
- 实际打印材料性能、切片参数、螺钉预紧力、相机螺纹有效啮合、释放力和冲击响应均需实测。
- 线性静力或谐响应模型不能替代非线性瞬态碰撞试验。

请阅读 [VALIDATION_STATUS.md](VALIDATION_STATUS.md)，了解证据边界和建议验收步骤。

## 制造提示

不要仅凭装配渲染图打印或安装。加工前必须核对单位、比例、法兰孔位、执行器安装孔、相机螺纹规格和有效旋入深度、线缆通道、间隙、打印方向、壁数、填充率及材料。机器人运动前先进行低能量试装与检查。
