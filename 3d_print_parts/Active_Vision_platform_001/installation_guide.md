# 主动视觉 2-DOF 云台 安装说明

## 1. 总览

本组件用于将 **Intel RealSense D415 深度摄像头** 安装至 **双轴 STS3032 舵机云台**，实现水平旋转（Yaw ±90°）和垂直俯仰（Pitch ±60°）两自由度运动。由 3 个 3D 打印结构件（001 底座、002 连接件、002_1 摄像头支架）、标准紧固件、舵机和摄像头组成。安装在机器人本体上后，配合 PICO 4 头显实现"头动视角动"的沉浸式远程视觉。

## 5. 装配步骤

### 5.1 准备工作

1. 检查 3D 打印件表面，如有支撑残留或毛刺，先清理干净。
2. 将两个 STS3032 舵机通过飞特 FD 调试软件分别设置 ID：**水平旋转舵机设为 ID=1，垂直俯仰舵机设为 ID=2**。波特率统一设为 **1000000**。
3. 确认所有紧固件数量齐全。

### 5.2 水平舵机 → 底座（001）

1. 将水平舵机（ID=1）放入 3D 打印底座 `001_2dof_head - G1_head_mount.stl` 的安装槽中。
2. 舵机输出轴朝**上**，舵机线从底座引出。
3. 用 **4 颗** ST2.2 × 4.5 自攻螺钉将水平舵机固定于底座。

### 5.3 垂直舵机 → 连接件（002）

1. 将垂直舵机（ID=2）放入 3D 打印连接件 `002_2dof_head - G1_head_mount.stl` 的安装槽中。
2. 用 **3 颗** ST2.2 × 4.5 自攻螺钉将垂直舵机固定于连接件。
3. 舵机线从连接件引出，注意预留弯曲余量。

### 5.4 URT-2 → 连接件侧面

1. 将 URT-2 调试板对准连接件（002）侧面预留的安装孔。
2. 用 **1 颗** M3 × 12 螺钉 + M3 螺母固定。

### 5.5 摄像头 → 摄像头支架（002_1）

1. 将 D415 摄像头放入摄像头支架 `002_2dof_head - G1_head_mount.stl _1`。
2. 底部用 **1 颗** M6 × 8 螺钉固定摄像头与支架。
3. 顶部用 **1 个** 柱塞 4.0 锁紧摄像头，防止晃动。

### 5.6 总装

1. 将两个舵脚分别安装至水平舵机和垂直舵机的输出轴。
2. 将装好垂直舵机的连接件（002）安装至**水平舵机**的舵脚上，锁紧。
3. 将装好摄像头的支架（002_1）安装至**垂直舵机**的舵脚上，锁紧。

### 5.7 接线

1. 将两个舵机的信号线按 ID 顺序串联：**URT-2 → ID=1（水平）→ ID=2（垂直）**。
2. URT-2 通过 Micro USB 线连接至 PC。
3. 舵机供电接入 URT-2 的电源端子（**12V，建议 3A 以上**）。
4. D415 摄像头 USB 3.0 数据线从支架后方引出，连接至 PC。

### 5.8 归中校准

1. 确认所有机械连接牢固，线缆无拉扯。
2. 舵机通电后，运行校准程序：

```bash
conda activate active_vision
cd windows   # 或 cd linux
python run.py --calibrate
```

3. 舵机自动扫描极限后锁定在 2048（中位）。
4. **手动旋转云台，使 D415 摄像头对准机器人正前方。**
5. 拧紧所有螺丝，按 Enter 完成校准。

## 7. 注意事项

- **调试前不要装支架**：有支架的舵机调试时可能夹手或堵转损坏舵机。先用 FD 软件设置好 ID 和波特率，再组装。
- **供电要求**：STS3032 12V 版本堵转电流大，两个舵机 + D415 同时工作需 12V 3A 以上电源。供电不足会导致舵机无力或通信异常。
- **舵机 ID 和波特率**：串联前必须先用 URT-2 单独连接每个舵机，通过 FD 软件修改 ID 为 1 和 2，波特率统一为 1000000。同一条总线上不能有相同 ID 的舵机。
- **归中方向**：校准后舵机锁定在 2048（中位）。此时摄像头应对准正前方。如果后续重新拆装，需重新运行 `--calibrate`。
- **线缆走线**：舵机线和 USB 线从引出，预留足够的弯曲余量，避免云台转动时拉扯导致松动或断裂。
- **打印件方向**：3D 打印件安装时注意方向，底座的光滑面朝外，安装槽应与舵机外形完全贴合。
- **URT-2 与 URT-1**：本设计使用 URT-2（新一代调试板）。如使用 URT-1，接线方式相同但物理尺寸可能略有差异，需自行调整固定方式。
